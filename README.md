# ivashenko.work

Production source for [ivashenko.work](https://ivashenko.work), published with GitHub Pages and a custom domain managed through GoDaddy.

## Included

- `/` personal editorial homepage
- `/projects/` selected work index
- `/projects/lovon/`, `/projects/aezakmi/`, `/projects/apex-bank/`, `/projects/emovi/`
- `/cv/` HTML CV plus downloadable PDF
- `/notebook/` animated under-construction archive, with no placeholder posts
- `sitemap.xml`, `robots.txt`, `404.html`
- Local Newsreader font, favicon, and Open Graph image

## Project imagery

Screenshots come from current official public App Store listings and are served locally for performance. Every case labels source and provenance. APEX and Emovi screens may show later product versions and are presented as current product context, not as proof that every visible detail was authored by Artyom.

## Technical profile

- Static HTML and CSS
- No client-side JavaScript
- No external runtime or font dependency
- Responsive layout and reduced-motion support
- Total source package around 1 MB before server compression

## Deployment

- GitHub Pages publishes the `main` branch.
- `CNAME` maps the site to `ivashenko.work`.
- The contact form posts to FormSubmit and may require first-use email activation.
