Контекст

LovOn, это AI-приложение для отношений и эмоциональной поддержки. Интерфейс должен выдерживать чувствительные разговоры, подписки, меняющееся поведение модели и живой голос, не показывая пользователю сложность под капотом.

Продуктовые решения значили не меньше кода: интерфейс обязан оставаться предсказуемым, даже когда сервис за ответом вероятностный.

Что сделал

  1. 01Нативное iOS-приложение на SwiftUI и UIKit, затем Android-клиент на React Native.
  2. 02Голосовое общение с AI-ассистентом в реальном времени через LiveKit и RetellAI: состояния подключения, слушания, речи, перебивания и сбоя смоделированы явно.
  3. 03Подписки с несколькими уровнями: StoreKit, RevenueCat, затем Adapty.
  4. 04Веб-воронка на React Native для рекламного трафика: первая AI-сессия и покупка в вебе, затем переход в приложение по диплинку.
  5. 05Онбординг и оптимизация рендеринга, которые подняли вовлечённость на 25%.
  6. 06Команда из трёх мобильных разработчиков, работа напрямую с бэкендом, продуктом, дизайном и маркетингом.

Инженерные решения

01

Архитектура идёт за продуктом

Быстрые итерации без превращения каждого нового поведения в хрупкий частный случай.

02

ИИ за надёжным контрактом

Мобильный слой владеет состояниями, повторами, обратной связью и UX вокруг вероятностного сервиса.

03

Голос, это состояние продукта

Подключение, слушание, речь, перебивание и ошибка, отдельные состояния с понятным интерфейсом.

04

Релиз не конец работы

Аналитика и поддержка показывают разрыв между задуманным и реальным поведением.
